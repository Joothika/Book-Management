# 📓 Book Management

**Book Management** is a mini MERN Application in which CRUD operation has been performed. Where users are able to visit books by genre and author, able to add new book and edit exisiting book also can delete

---

## 🛡 Features

- Books Listing
- Admin access like Create, Update, Delete for books
- Deployment through catalyst by zoho

---

## 🧰 Tech Stack

| Layer | Technology |
|------ | ---------- |
| **Frontend** | React.js , Tailwindcss |
| **Backend** | Node.js, Express.js |
| **Database** | MongoDB |
| **Deployment** | Zoho Catalyst |

---

## ⚙️ Development Setup

### Frontend Setup

```bash

# Navigate to frontend
cd frontend

# Install dependencies
npm install or npm i

# Run frontend
npm run dev

```

### Backend Setup

```bash

# Navigate to backend
cd backend

# Install dependencies
npm install or npm i

# Configure .env file
MONGO_URI = 'place the url'

# Run frontend
npm run dev

```
